# 数据质量平台技术方案 v0.1

> 基于 Great Expectations 的内部数据质量平台  
> 前端 Vue 3 · 后端 Python(FastAPI) · 定时调度 · 产品级  

---

## 一、技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| **前端** | Vue 3 + Element Plus + Formily(Vue) | Element Plus 表格/表单成熟，Formily 做动态表单 |
| **后端** | FastAPI + SQLAlchemy + Celery | FastAPI 异步高性能，Celery 做定时调度 |
| **规则引擎** | Great Expectations 0.18+ | 核心校验引擎 |
| **存储** | PostgreSQL + Redis | PG 存规则/历史/配置，Redis 做 Celery broker + 缓存 |
| **调度** | Celery Beat | 定时任务调度，支持 cron 表达式 |
| **通知** | 飞书 Webhook + SMTP 邮件 | 内部团队首选飞书 |

## 三、核心数据模型

```sql
-- 数据源
CREATE TABLE datasources (
    id              SERIAL PRIMARY KEY,
    name            VARCHAR(100) NOT NULL,
    type            VARCHAR(20) NOT NULL,          -- mysql / postgresql / csv / api
    connection_config JSONB NOT NULL,              -- 加密存储
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW(),
    created_by      VARCHAR(50)
);

-- 规则集（一个数据源 N 个规则集）
CREATE TABLE rule_suites (
    id              SERIAL PRIMARY KEY,
    datasource_id   INTEGER REFERENCES datasources(id),
    name            VARCHAR(100) NOT NULL,
    description     TEXT,
    target_table    VARCHAR(200),                  -- 校验的表/文件
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- 规则（一个规则集 N 条规则）
CREATE TABLE rules (
    id              SERIAL PRIMARY KEY,
    suite_id        INTEGER REFERENCES rule_suites(id),
    expectation_type VARCHAR(100) NOT NULL,        -- GX expectation 方法名
    kwargs          JSONB NOT NULL,                -- 参数
    meta            JSONB,                         -- severity / desc / 自定义
    mostly          FLOAT DEFAULT 1.0,             -- 容忍度 0-1
    is_active       BOOLEAN DEFAULT TRUE,
    sort_order      INTEGER DEFAULT 0,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 调度配置
CREATE TABLE schedules (
    id              SERIAL PRIMARY KEY,
    suite_id        INTEGER REFERENCES rule_suites(id),
    cron_expr       VARCHAR(50) NOT NULL,          -- "0 9 * * *" 每天9点
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 执行历史
CREATE TABLE validation_runs (
    id              SERIAL PRIMARY KEY,
    suite_id        INTEGER REFERENCES rule_suites(id),
    status          VARCHAR(20) NOT NULL,          -- running / success / failed / error
    total_rules     INTEGER,
    passed_rules    INTEGER,
    failed_rules    INTEGER,
    started_at      TIMESTAMP DEFAULT NOW(),
    finished_at     TIMESTAMP,
    trigger_type    VARCHAR(20),                   -- schedule / manual
    detail          JSONB                           -- GX 完整结果
);

-- 通知配置
CREATE TABLE notification_configs (
    id              SERIAL PRIMARY KEY,
    suite_id        INTEGER REFERENCES rule_suites(id),
    channel         VARCHAR(20) NOT NULL,          -- feishu / email / webhook
    target          VARCHAR(500) NOT NULL,          -- webhook URL / 邮箱列表
    trigger_on      VARCHAR(20) NOT NULL,           -- always / on_failure
    min_severity    VARCHAR(20) DEFAULT 'warning',  -- error / warning / info
    template_id     VARCHAR(50)                     -- 消息模板
);

-- 告警日志
CREATE TABLE alert_logs (
    id              SERIAL PRIMARY KEY,
    run_id          INTEGER REFERENCES validation_runs(id),
    channel         VARCHAR(20),
    content         TEXT,
    status          VARCHAR(20),                    -- sent / failed
    sent_at         TIMESTAMP DEFAULT NOW()
);
```

### 规则模板库（P0 先做 8 个）

| # | 模板名称 | GX 方法 | 前端表单参数 | 适用字段类型 |
|---|---------|---------|-------------|-------------|
| 1 | 非空检查 | `expect_column_values_to_not_be_null` | 无额外参数 | 全部 |
| 2 | 唯一性检查 | `expect_column_values_to_be_unique` | 无额外参数 | 全部 |
| 3 | 数值范围 | `expect_column_values_to_be_between` | min, max, mostly | 数值 |
| 4 | 正则匹配 | `expect_column_values_to_match_regex` | regex（含预设：邮箱/手机号/身份证/URL） | 字符串 |
| 5 | 枚举值 | `expect_column_values_to_be_in_set` | value_set（标签输入） | 全部 |
| 6 | 值长度 | `expect_column_value_lengths_to_be_between` | min, max | 字符串 |
| 7 | 日期范围 | `expect_column_values_to_be_between`（解析日期） | start_date, end_date | 日期 |
| 8 | 跨列比较 | `expect_column_pair_values_A_to_be_greater_than_B` | column_A, column_B, or_equal | 数值 |

### 规则分层设计

```
Layer 1: 规则模板（覆盖 80% 场景）
├── 完整性：非空检查
├── 唯一性：重复值检查
├── 范围：数值区间 [min, max]
├── 格式：正则匹配（邮箱/手机号/身份证...）
├── 枚举：值必须在指定集合内
├── 一致性：两列关系（A > B / A = B + C）
├── 分布：均值/标准差/分位数
└── 关联：跨表外键完整性

Layer 2: 高级规则（覆盖 15% 场景）
├── SQL 自定义查询规则
├── 多列组合校验
└── 条件规则（when A is null then B must...）

Layer 3: 自定义代码（覆盖 5% 场景）
└── 直接写 Python Expectation（给高级用户）
```

### 前端交互关键点

1. **选完字段自动推荐规则** — 用户选了 `email` 列，自动推荐"正则匹配""非空""唯一"；选了 `age` 列，自动推荐"范围检查"
2. **每条规则必须能单独试跑** — 配完立即点"测试"，返回通过率 + 失败样本
3. **mostly（容忍度）参数必须显眼** — "允许 0.1% 的异常"和"必须 100% 通过"是完全不同的业务语义
4. **规则集管理** — 一个数据源可以有多套规则集（日常校验 vs 上线前校验）

### 规则翻译（后端核心）

```python
# service/rule_engine.py
import great_expectations as gx
from typing import List, Dict

class RuleEngine:
    """将 DB 存的 JSON 规则翻译成 GX Expectation 执行"""

    def __init__(self, datasource_config: dict):
        self.context = gx.get_context()
        self.datasource = self._connect(datasource_config)

    def run_suite(self, suite_rules: List[Dict], table: str) -> dict:
        """
        执行一个规则集
        suite_rules: [{expectation_type, kwargs, mostly, meta}]
        table: 校验目标表
        """
        df = self._load_data(table)

        suite = gx.ExpectationSuite(name="temp_suite")
        for rule in suite_rules:
            if not rule["is_active"]:
                continue
            expectation = self._build_expectation(rule)
            suite.add_expectation(expectation)

        result = self.context.run_checkpoint(
            expectation_suite=suite,
            batch_parameters={"datasource": self.datasource, "table": table}
        )
        return self._format_result(result)

    def _build_expectation(self, rule: dict):
        """JSON 规则 → GX Expectation 对象"""
        exp_type = rule["expectation_type"]
        kwargs = rule["kwargs"]
        mostly = rule.get("mostly", 1.0)

        return gx.ExpectationConfiguration(
            expectation_type=exp_type,
            kwargs={**kwargs, "mostly": mostly},
            meta=rule.get("meta", {})
        )

    def _format_result(self, result) -> dict:
        """GX 原始结果 → 前端友好格式"""
        return {
            "success": result.success,
            "statistics": {
                "evaluated_expectations": result.statistics["evaluated_expectations"],
                "successful_expectations": result.statistics["successful_expectations"],
                "unsuccessful_expectations": result.statistics["unsuccessful_expectations"],
            },
            "details": [
                {
                    "expectation_type": r.expectation_config.expectation_type,
                    "success": r.success,
                    "result": {
                        "unexpected_count": r.result.get("unexpected_count", 0),
                        "unexpected_percent": r.result.get("unexpected_percent", 0),
                        "unexpected_index_list": r.result.get("unexpected_index_list", [])[:20],
                        "observed_value": r.result.get("observed_value"),
                    },
                    "meta": r.expectation_config.meta,
                }
                for r in result.results
            ]
        }
```

### 智能推荐（选字段自动推荐规则）

```python
# service/rule_recommender.py

COLUMN_TYPE_MAP = {
    "int": ["not_null", "unique", "between", "in_set"],
    "bigint": ["not_null", "unique", "between", "in_set"],
    "decimal": ["not_null", "between", "in_set"],
    "varchar": ["not_null", "unique", "match_regex", "length_between", "in_set"],
    "text": ["not_null", "match_regex", "length_between"],
    "datetime": ["not_null", "date_between"],
    "date": ["not_null", "date_between"],
}

REGEX_PRESETS = {
    "邮箱": r"^[\w.+-]+@[\w-]+\.[\w.-]+$",
    "手机号": r"^1[3-9]\d{9}$",
    "身份证号": r"^\d{17}[\dXx]$",
    "URL": r"^https?://[\w\-]+(\.[\w\-]+)+[\w\-\._~:/?#[\]@!\$&'\(\)\*\+,;=]+$",
    "统一社会信用代码": r"^[0-9A-HJ-NPQRTUWXY]{2}\d{6}[0-9A-HJ-NPQRTUWXY]{10}$",
}

def recommend_rules(column_name: str, column_type: str, samples: list) -> list:
    """根据字段类型 + 样本推荐规则"""
    base_type = column_type.lower().split("(")[0]
    rules = COLUMN_TYPE_MAP.get(base_type, ["not_null"])

    name_lower = column_name.lower()
    if "email" in name_lower or "邮箱" in name_lower:
        rules.append("match_regex_email")
    elif "phone" in name_lower or "手机" in name_lower:
        rules.append("match_regex_phone")
    elif "id" in name_lower or "编号" in name_lower:
        rules.append("unique")

    return rules
```

```python
# service/notification.py
import httpx
import smtplib
from email.mime.text import MIMEText
from datetime import datetime

class NotificationService:

    async def send_feishu(self, webhook_url: str, result: dict, suite_name: str):
        """飞书 Webhook 推送"""
        card = self._build_feishu_card(result, suite_name)
        async with httpx.AsyncClient() as client:
            resp = await client.post(webhook_url, json=card)
            return resp.status_code == 200

    def _build_feishu_card(self, result: dict, suite_name: str) -> dict:
        """构建飞书消息卡片"""
        failed = [d for d in result["details"] if not d["success"]]
        passed = [d for d in result["details"] if d["success"]]

        is_success = result["success"]
        header_color = "green" if is_success else "red"
        header_title = f"{'✅' if is_success else '🔴'} 数据质量校验{'通过' if is_success else '告警'}"

        elements = []
        for f in failed[:5]:  # 最多展示 5 条
            elements.append({
                "tag": "div",
                "text": {
                    "tag": "lark_md",
                    "content": f"**❌ {f['meta'].get('desc', f['expectation_type'])}**\n"
                               f"失败数量：{f['result']['unexpected_count']}\n"
                               f"异常比例：{f['result']['unexpected_percent']:.2f}%"
                }
            })

        if len(failed) > 5:
            elements.append({
                "tag": "div",
                "text": {"tag": "lark_md",
                         "content": f"...还有 {len(failed) - 5} 条失败规则，点击查看详情"}
            })

        return {
            "msg_type": "interactive",
            "card": {
                "header": {
                    "title": {"tag": "plain_text", "content": header_title},
                    "template": header_color
                },
                "elements": [
                    {"tag": "div", "text": {"tag": "lark_md",
                        "content": f"**规则集：** {suite_name}\n"
                                   f"**总规则：** {result['statistics']['evaluated_expectations']}\n"
                                   f"**通过：** {result['statistics']['successful_expectations']}\n"
                                   f"**失败：** {result['statistics']['unsuccessful_expectations']}\n"
                                   f"**时间：** {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}"}},
                    {"tag": "hr"},
                    *elements,
                    {"tag": "action", "actions": [{
                        "tag": "button",
                        "text": {"tag": "plain_text", "content": "查看详情"},
                        "url": f"https://dq.internal.company.com/runs/{result['run_id']}",
                        "type": "primary"
                    }]}
                ]
            }
        }

    async def send_email(self, to_addrs: list, result: dict, suite_name: str):
        """邮件推送"""
        subject = f"[数据质量] {suite_name} - {'通过' if result['success'] else '告警'}"
        html = self._build_email_html(result, suite_name)
        msg = MIMEText(html, "html", "utf-8")
        msg["Subject"] = subject
        msg["From"] = SMTP_CONFIG["from"]
        msg["To"] = ", ".join(to_addrs)
        with smtplib.SMTP(SMTP_CONFIG["host"], SMTP_CONFIG["port"]) as s:
            s.send_message(msg)
```

### 频率控制（告警去重）

```python
# service/alert_dedup.py

class AlertDeduplicator:
    """告警去重：同一规则集连续失败不刷屏"""

    async def should_send(self, suite_id: int, channel: str) -> bool:
        """检查是否应该发送（首次即报，后续按间隔）"""
        key = f"alert:suite:{suite_id}:{channel}"
        last_sent = await redis.get(key)

        if last_sent is None:
            await redis.setex(key, MIN_ALERT_INTERVAL_SECONDS, "1")
            return True
        return False

    async def resolve(self, suite_id: int, channel: str):
        """规则集恢复通过时，发一条恢复通知并清除状态"""
        key = f"alert:suite:{suite_id}:{channel}"
        await redis.delete(key)
```

### 关键设计点

1. **通知带上下文** — 哪条规则、期望什么、实际什么、异常比例多少
2. **通知频率控制** — 同一规则集连续失败合并通知（首次即报 + 后续按间隔）
3. **分级推送** — error 推飞书+邮件，warning 只推飞书，info 只记录

```python
# scheduler/celery_app.py
from celery import Celery
from celery.schedules import crontab

app = Celery("dq_platform", broker=REDIS_URL, backend=REDIS_URL)

# 动态注册定时任务（从 DB 读取 schedule 配置）
@app.on_after_configure.connect
def setup_schedules(sender, **kwargs):
    schedules = db.query(Schedule).filter(is_active=True).all()
    for sched in schedules:
        suite_name = f"suite_{sched.suite_id}"
        cron_parts = parse_cron(sched.cron_expr)
        sender.conf.beat_schedule[suite_name] = {
            "task": "tasks.run_validation",
            "schedule": crontab(**cron_parts),
            "args": [sched.suite_id],
        }

@app.task
def run_validation(suite_id: int):
    """执行校验任务（定时触发 / 手动触发）"""
    suite = db.query(RuleSuite).get(suite_id)
    rules = db.query(Rule).filter(suite_id=suite_id, is_active=True).all()

    # 1. 执行 GX 校验
    engine = RuleEngine(suite.datasource.config)
    result = engine.run_suite(rules, suite.target_table)

    # 2. 存执行记录
    run = ValidationRun(suite_id=suite_id, ...)
    db.add(run)
    db.commit()

    # 3. 触发通知
    if not result["success"]:
        notify = NotificationService()
        configs = db.query(NotificationConfig).filter(suite_id=suite_id).all()
        for cfg in configs:
            if should_notify(cfg, result):
                await notify.send(cfg, result, suite.name)
```
